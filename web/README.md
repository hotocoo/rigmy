# RigMY web

Next.js 16 app. See the [root README](../README.md) for running the stack and [docs/FRONTEND.md](../docs/FRONTEND.md) for the standards (design tokens, UI kit, routes, no hardcoding).

```
src/app/          routes (thin server components)
src/components/   ui/ (kit), shell/ (nav, transitions), page areas: home, build, parts, commerce, market, location
src/lib/          tokens, routes, data (API + WASM engine), content, store, format, location, chart
src/studio/       three.js 3D build studio
src/wasm/         generated by ../scripts/build-wasm.sh — do not edit
```
